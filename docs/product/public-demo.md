# 公開デモ運用

Aimani AI の公開デモは、チームの作業を眺めて責任を引き継ぐ体験を共有するための環境です。

## ログイン

seedのownerアカウントを使います。

```text
owner@aimani-ai.local
aimani-ai-demo-2026
```

これは共有デモ専用の固定資格情報で、機密ではありません。本番の個人アカウントや他サービスのパスワードとして使わないでください。

## リセット方針

デモデータは決定論的なseedです。状態が変わったら `pnpm db:demo:reset` で初期状態へ戻します。入力したデータは保存・復元を保証せず、リセットで消える前提です。個人情報、顧客情報、秘密情報は入力しないでください。

## Process Lab

Process Lab は工程と依存関係を試すための試験機能です。正式な業務データの保管場所ではなく、仮説検証後に削除できる機能として扱います。
